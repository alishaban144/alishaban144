 # Ali Shaaban

M.Sc. student in Digital Transformation at FH Dortmund, with a B.Sc. in Computer Science. My work combines software development, applied AI and experience in web analytics and science communication.

## Selected projects

### [Aliflix](https://github.com/alishaban144/aliflix-android)
**Independent Android project · Kotlin, Jetpack Compose, Cloudflare Workers, Firebase**

A native Android application for discovering films and series. I develop the mobile application and its recommendation backend.

- Built a feature that turns a description of what someone wants to watch into title recommendations, checked against TMDB catalogue data before display.
- Added catalogue-based fallback paths when AI services are unavailable, together with filtering and recommendation-session handling.
- Maintain signed mobile releases through GitHub Actions, with APK integrity checks and in-app update support.

[Source code](https://github.com/alishaban144/aliflix-android) · [Latest release](https://github.com/alishaban144/aliflix-android/releases/latest)

### [Park and Charge](https://github.com/usmanrangrez/dmsa-sose2026-NullPointers)
**University team project · Microservices, REST APIs, Docker**

An EV charging platform connecting drivers and charging-station owners. My contribution focused on user accounts, authentication, profiles and role-based access within the wider service architecture.

[Project and documentation](https://github.com/usmanrangrez/dmsa-sose2026-NullPointers) · [Architecture](https://github.com/usmanrangrez/dmsa-sose2026-NullPointers/blob/main/ARCHITECTURE.md)

### [Yerba Vibe](https://github.com/alishaban144/mate-new)
**Web application · Vue, Node.js, Express, REST and GraphQL**

A multilingual café application with a product menu, basket and brewing guide, built with a Vue frontend and an Express backend.
