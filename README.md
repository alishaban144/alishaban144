## Projects

### [Aliflix](https://github.com/alishaban144/aliflix-android)
**Independent developer · Native Android application and recommendation backend**

- Develop the mobile application in **Kotlin and Jetpack Compose**, integrating external APIs and HTTP services for catalogue data, discovery and account features.
- Build AI-assisted recommendations with **Groq and Gemini**, validating suggested titles against **TMDB** metadata and applying catalogue-based fallbacks when AI services are unavailable.
- Implement backend request handling, filtering and recommendation sessions with **TypeScript, Cloudflare Workers and Durable Objects**, with Firebase for account and synchronisation features.
- Maintain **GitHub Actions** workflows for testing and signed mobile releases, including APK signer, size and SHA-256 checks.
- Improve functionality and usability through iterative development, regression checks and scenario-based testing.
